# DCW Montage media

Add the 8 web-optimized film files (`film-01.mp4` through `film-08.mp4`) and matching poster images (`poster-01.jpg` through `poster-08.jpg`) to this folder. The Hospitality > Videos > Montage gallery automatically displays available files.

The website and gallery are maintained on the `dcw-cinematic-portfolio` branch. UGC Style is a separate collection.
